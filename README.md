# 思想刷题客 (ThoughtSlasher) 🚩

> 《习近平新时代中国特色社会主义思想概论》期末刷题通关神器！  
> 纯前端离线单页应用（SPA / PWA），专为手机端与电脑端优化，支持国内驾考宝典式即选即判、智能错题攻坚本、分章/全库混刷与 100 分全真均衡模拟卷！

---

## ✨ 核心特性

1. **驾考级“即选即判”极速刷题**：
   - **单选题**：点击选项瞬间判定对错（正确显示翠绿并加勾、错误标红并标明你的选择），零延迟展示答案与详细解析。
   - **多选题**：支持直观多项勾选，点击“确认提交”后即刻判定（对、漏、错高亮展示）。
   - **答对自动下一题**：开启后答对自动平滑滑入下一题；答错自动驻留当前题，便于沉淀吸收考点。
2. **深度解析与考场秒杀口诀**：
   - 每道题目均配备**【🎯 核心考点】**、**【📖 深度解析】**与**【💡 考场秒杀口诀】**，直击易混淆概念与论断关键词。
3. **智能错题攻坚本 (记录做错遍数)**：
   - 凡是做错的题目自动收入错题本，并累加记录“已累计做错 X 次”；
   - 专属错题重练模块：高频易错题优先排前攻坚；
   - 彻底掌握后可一键“🎉 移出错题本”。
4. **灵活多样的刷题模式**：
   - **按章节独立刷题**：全书 18 个章节（导论 + 第1章至第17章），可随时独立进入某一章精准突破；
   - **全题库混合刷题**：打乱章节界限，支持“🎲 随机乱序刷”与“🔢 顺序连贯刷”两种模式。
5. **全真模拟考场 (100分制 · 45分钟倒计时)**：
   - **全章节均匀分布抽题**：从全书 18 个章节均匀抽题，包含 **25 道单选（每题 2.4 分，共 60 分）** + **10 道多选（每题 4 分，共 40 分）**，整套试卷满分 100 分；
   - **沉浸考场体验**：45 分钟倒计时、实时答题卡、交卷二次确认；
   - **权威成绩单与逐题复盘**：考后出具成绩报告、分数等级、用时统计与 35 题全景答题卡，点击任意题号直接进入试卷复盘模式！
6. **电脑端键盘盲操快捷键**：
   - `A` / `B` / `C` / `D`：极速选定选项；
   - `Enter`：提交多选题 / 下一题；
   - `←` / `→`：切换上一题 / 下一题。
7. **数据本地化与离线支持**：
   - 做题历史、错题记录与模拟卷战绩全量存储于浏览器本地（LocalStorage），无须注册登录，无隐私泄露风险。
