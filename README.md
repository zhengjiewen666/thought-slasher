# 刷题客 (ThoughtSlasher) 🚩

> 《习近平新时代中国特色社会主义思想概论》期末刷题通关神器！  
> 纯前端离线单页应用（SPA / PWA），专为手机端与电脑端优化，支持国内驾考宝典式即选即判、跨端无缝实时云同步、智能错题攻坚本、分章/全库混刷与 45 分全真均衡模拟卷！

---

## ✨ 核心特性

1. **跨端实时无缝云同步 (零配置 · 手机/电脑数据实时互通)**：
   - 内置基于 GitHub Gist + Vercel Serverless Function 的高可用云同步引擎；
   - 手机端刷过的题、做错的题和模考成绩，在电脑端打开立即自动合并更新，反之亦然；
   - 顶部实时展示同步胶囊状态（`☁️ 同步中...` / `☁️ 已同步`），支持点击手动强推，同时在离线或本地环境下自动降级本地存储，联网即同步。
2. **驾考级“即选即判”极速刷题**：
   - **单选题**：点击选项瞬间判定对错（正确显示翠绿并加勾、错误标红并标明你的选择），零延迟展示答案与详细解析。
   - **多选题**：支持直观多项勾选，点击“确认提交”后即刻判定（对、漏、错高亮展示）。
   - **答对自动下一题**：开启后答对自动平滑滑入下一题；答错自动驻留当前题，便于沉淀吸收考点。
3. **深度解析、各选项深度辨析与考场秒杀口诀**：
   - 每道题目均配备**【🎯 核心考点】**、**【📖 深度解析】**、**【🔍 各选项深度剖析】**与**【💡 考场秒杀口诀】**；
   - **选项逐项全面剖析**：不仅解释正确答案，还对所有干扰选项逐项剖析其理论定位与易混淆点（如“五位一体”中经济建设是中心、政治是保障、文化是灵魂、社会是条件、生态文明是基础等），一题串联全部考点！
4. **智能错题攻坚本 (「背诵模式」与「重做模式」双版本自由切换)**：
   - **📖 错题背诵模式 (带答案与解析直出)**：正确答案自动标绿勾选，深度解析与选项逐项剖析完全展开，无需作答直接高效背诵，专供考前突击！
   - **✍️ 错题重练模式 (无剧透闭卷实测)**：答案与解析完全隐藏，真实重刷自测，做对后可一键“🎉 移出错题本”，检验记忆成效；
   - **无缝一键互切**：首页卡片可一键切换默认模式，刷题过程中右上角也可随时一键在“📖 背题模式”与“✍️ 做题模式”间自由互切；
   - **按章节分类与动态错频精准分层**：首页动态按准确错误次数自动分组（错1次 / 错2次 / 错3次 / 错4次 / 错5次...甚至错10次+），并严格**按最新做错时间顺序优先排列**（刚做错的排在最前），同时支持按章节逐章直出“📖 背错题”与“✍️ 练错题”双按钮；
   - **每轮结束闭环巩固流（先背再刷）**：每刷完一轮错题自动弹出结算面板，支持一键**「📖 先背本轮错题」**先看清答案与解析，背完后按钮引导**「✍️ 立即再刷一遍」**打乱选项趁热打铁闭卷复测！
5. **选项智能随机打乱机制 (防死记位置 · 真实掌握考点内涵)**：
   - **彻底杜绝位置肌肉记忆**：每次做题（章节练习、错题重刷、错题背诵、全库混刷、模拟考试），系统自动对选项进行 Fisher-Yates 随机打乱重排，杜绝死记 A/B/C/D 位置，倒逼真正读懂选项表述；
   - **智能锁定方向性选项**：自动识别诸如“以上都是”等特殊表述，确保其智能固定于选项末位，其余选项充分乱序；
   - **单题即时重试重洗牌**：解析卡片提供「🔄 重新作答 (打乱选项)」按钮，随时一键重置单题作答并生成全新排列自测；
   - **全局自由开关**：顶部答题栏配有「🔀 选项随机」专属开关（默认开启），支持随心切换回标准默认顺序。
6. **灵活多样的刷题模式**：
   - **按章节独立刷题**：全书 18 个章节（导论 + 第1章至第17章），可随时独立进入某一章精准突破；
   - **全题库混合刷题**：打乱章节界限，支持“🎲 随机乱序刷”与“🔢 顺序连贯刷”两种模式。
7. **全真模拟考场 (45分制 · 45分钟倒计时)**：
   - **全章节均匀分布抽题**：从全书 18 个章节均匀抽题，包含 **25 道单选（每题 1 分，共 25 分）** + **10 道多选（每题 2 分，共 20 分）**，整套试卷满分 45 分；
   - **沉浸考场体验**：45 分钟倒计时、实时答题卡、交卷二次确认；
   - **权威成绩单与逐题复盘**：考后出具成绩报告、分数等级、用时统计与 35 题全景答题卡，点击任意题号直接进入试卷复盘模式！
7. **电脑端键盘盲操快捷键**：
   - `A` / `B` / `C` / `D`：极速选定选项；
   - `W` / `?`：触发“🤷 我不会”直接显示解析并记入错题；
   - `Enter`：提交多选题 / 下一题；
   - `←` / `→`：切换上一题 / 下一题；
   - `Esc`：快速返回上一层级或关闭弹窗。
8. **双模式灵动手势系统 (全真跟手物理动感)**：
   - **📱 屏幕左边缘右划（边边划）**：手指从屏幕左侧边缘（≤ 48px）从左往右滑，页面/弹窗随手指实时横向平移，滑过阈值即顺滑滑出屏幕，退出并返回上一层级；
   - **🃏 非边缘区域滑动（跟手动感切题）**：在题目卡片区域，手指拖拽时卡片随手指 1:1 动态位移并带有灵动物理微倾角：
     - **从左往右划**：卡片右滑切出，**上一题**自左侧弹性滑入居中；
     - **从右往左划**：卡片左滑切出，**下一题**自右侧弹性滑入居中；
     - **弹性阻尼与回弹**：第一题向右拉或最后一题向左拉时具备橡皮筋阻尼效果，未达阈值松手自然弹性回正。
